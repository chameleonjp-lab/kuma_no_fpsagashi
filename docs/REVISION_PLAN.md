# 改修計画書（リビジョンv2）

依頼日 2026-06-14 ／ 依頼者フィードバックに基づく改修。正本仕様は docs/game-spec.md（v1.1）。
本改修で v1.1 と異なる挙動になる項目は、依頼者の明示指示として `docs/decisions.md` に「v2変更」として記録する。

## 0. 方針

- 公開正本 `index.html` 単一ファイルを維持。音声・外部読込・ビルドなしを維持。
- CORE層（CORE-BEGIN〜END）は DOM 非依存を維持し、`tools/core-harness.mjs` で回帰検証する。
- 既存の受け入れ（§13）を壊さない。独り言41行・ランキングXSS対策・タッチ抑止は維持。
- バッチ単位で実装→ハーネス→コミット。難所はメインセッション（Opus）が直接、定型の大物UIはOpusサブエージェント。

A5. **獲得経験値をログ表示**：撃破時「経験値を N かくとく」。

### バッチB：戦闘ビジュアル・フィードバック（RENDER）
B1. **攻撃エフェクト（爪痕）**：熊が攻撃した方向の敵タイルに、引っ掻き（3本線）を短時間表示。
B2. **被弾点滅0.2秒**：敵が攻撃を受けたら、その敵を0.2秒点滅。熊が攻撃を受けたら🐻を0.2秒点滅。
B3. **熊への被弾エフェクト**：敵から攻撃された時、🐻に被弾エフェクト（衝撃マーク）。
B4. **敵HPバー**：視界内の各敵の頭上に小さなHPバー（現HP/最大HP）。
B5. **向き矢印**：🐻の向いている隣接1マスに、薄い茶色系の方向矢印を常時表示（空振り防止の視認性）。
- 実装：Core.act / 敵フェーズが構造化fxイベント（{t:'fx',kind,x,y}）を events に積み、Game.playerAction が Render.addEffect へ転送。Render は時限エフェクト配列を毎フレーム描画・減衰。CORE層はDOM非依存のままデータのみ生成。

### バッチC：メニュー・持ち物・装備の刷新（MENU）
C1. **アイテム名タップで効果説明**：持ち物の各行の名前タップで効果文を表示（食料は「満腹度+50」等の具体値）。
C2. **装備ボタン表記**：装備品（武器/盾）の行ボタンを「使う」→「装備」に。
C3. **装備したら装備欄へ移動**：装備中アイテムは持ち物一覧から消え、装備タブに表示（内部はinv保持のまま表示分離）。
C4. **装備タブに部位表示**：「武器」「盾」の各部位の現在装備を表示。
C5. **部位ごとに 装備/外す ボタン**：外す＝持ち物一覧へ戻す。装備＝下記C6。
C6. **部位の装備ボタン**：押すと持ち物内の該当部位装備可能アイテムを選択肢表示。無ければ「装備できる持ち物がない」。
C7. **所持数表示 N/10**：持ち物タブ見出しに「持ち物 N/10」。
C8. **装備時にメニューを閉じない**：use(weapon/shield) 後は Menu.render() で再描画し開いたまま（playerActionに「メニュー維持」オプション）。食料/回復/投擲はこれまで通り閉じる。
- 装備はターン消費（§8.4「付け替えは1ターン消費」）を維持するが、メニューを開いたまま敵ターンを進める。

### バッチD：テキスト・ランキング・操作ボタン
D1. **結果コメント FP→ファーストパートナー**：「熊はファーストパートナーを見つけられないまま倒れた…」。タイトル「熊のFP探し」は変更しない（依頼は結果画面コメント）。
D2. **ランキング自動送信**：結果画面表示と同時に自動送信（手動「ランキングに登録」廃止）。二重送信防止・送信中/成功/失敗表示は維持。名前未入力時は既定名で送信（あるいは未送信表示）。johba作法に整合。§9.3-1（手動送信）からの変更として記録。
D3. **操作ボタン拡大**：dpad 48→56px、攻撃ボタン拡大、足踏み/メニュー拡大、フォント増。375px幅に収まることを確認。

## 2. 影響範囲とハーネス更新

- CONFIG：REGEN_EVERY_TURNS、（新規敵スケール定数）。
- DATA.ENEMIES：新規10種追加・既存2種のmaxF変更。
- ハーネス：data（新規敵の数値）、formulas（新規敵スケール）、gen（🌀の非チョーク配置）、items（既存維持）、bot（深層到達・新規敵撃破可能性）。新グループ `beatable`（各新規敵を相応プレイヤーで撃破できるか）を追加。
- 独り言・ランキングXSS・タッチ抑止の既存テストは不変で維持。
