# 修正計画書 v5 — 深層オーバーホール（B60到達を数学的に可能に）

作成 2026-06-17 ／ 依頼: 「60層到達を数学的可能な状態に。ただし運が絡んでようやく到達は維持」。
許可: ①B40以降の段階的な装備追加 ②便利アイテムの追加 ③Lv上限を適切な範囲まで増やす ④移動キーの拡大。
進め方: Opusで役割分担（バランス／コンテンツ／モバイルUX）→ 本書に確定 → 実装。

## 背景（v4までの結論）

敵は線形に無限上昇（deepScale rate0.08）、プレイヤーはLv30＋最強装備で頭打ち。理論壁は約B47で、B60はいかなる合法プレイでも到達不能だった（`tools/ceiling-analysis.mjs`）。本v5は**プレイヤー側の上限のみ**引き上げて壁をB60へ押し上げる（敵スケーリングは変更しない＝依頼者制約）。B1〜B30は一切変更しない。

## 確定（3視点の統合）

### バランス（数値・`tools/balance-v5-check.mjs`で検証済み）
- **LV_MAX 30→42**。Lv42でLv30比 +72maxHp / +12攻 / +4防。B60を辛勝、B55以下未到達者は壁、の幅を作る最小値。
- **経験値式 piecewise**（Lv1〜30は現行と完全一致＝B1〜30保護）:
  - n≤30: `ceil(6×1.20^(n-1))`（不変、xpNeed(30)=1187）
  - n≥31: `1187 + (n-30)×650`（線形）。xpNeed(35)=4437・(40)=7687・(42)=8987。
  - Lv30→42到達には B31〜60をほぼ毎フロア完全狩り（約57k XP・1レベル≈1.2〜3.1フロア）が必要＝徹底＋幸運なプレイのみ。
- **新武器ツメ4段**（+5atk/約+4F）: 41(minF43) / 46(47) / 51(51) / 56(55)。
- **新盾毛皮4段**（+4def/約+4F）: 36(43) / 40(47) / 44(51) / 48(55)。
- 既存トップ（でんせつ/ほし）に maxF を付与しバンド化（深層で弱装備が居座らないように）。
- **新便利アイテム5種**（すべて既存の effects フックを再利用＝CORE改修不要）:
  - 深層の防御無視投擲（dmg24・scale1.1・貫通・minF40）
  - 最大HP草（drink/maxhp power8・minF36）
  - 強い強化巻 武器/盾（read/enhance power5・minF40）
  - 守りの大飾り（passive/statAdd def+6・minF36）
- 検証結果（期待値モデル）: **B60 LUCKY=WIN（素殴りでも8手撃破・被弾耐え、余裕+96）／B60 AVG=LOSE（−890）**。平均的プレイの壁は B47〜B50 のまま。よって「運＋最適でようやくB60」を満たす。

### コンテンツ（世界観・命名）
- 新装備テーマは 星(ほし)の先の宇宙的エスカレーション: **ながれぼし→あまのがわ→そら→あけぼの**（流れ星→天の川→空→夜明け）。武器=「〜のツメ」、盾=「〜の毛皮」。
- 絵文字はFPセット🐾と衝突させない（FP最終装備の identity を保つ）。各段の武器/盾はFPセット同様にティア絵文字を共有（☄️🌌🪐🌅）。
- 新アイテム名: ほしくだきの矢🌠 / おおいのち草🌱 / つよいつめ上げの伝え葉📜 / つよいまもり上げの伝え葉📜 / まもりの大かざり🔔。

### モバイルUX（移動キー拡大・Proposal A）
- `#dpad` 上下左右セル 66→**76px**（+15%・誤タップ防止で斜め四隅は50→**52px**）。`#controls` gap8→6・padding 8/10→7/8、`#actionBtns` 150→**140px**で横幅を捻出。
- 結果: dpad 186×186・controls高 +12px・キャンバス 344→332px（−3.5%、支障なし）・横スクロールなし・全タップ≥52px。中央🐻と`.dirBtn`系は100%充填で自動追従。
