# 熊のFP探し（kuma_no_fpsagashi）

スマホブラウザ向け・ターン制ローグライク。

主人公の熊が、FP（ファーストパートナー）を探して底なしのダンジョンへ潜っていく。
スコアは**最深到達階**（B◯F）。死亡またはあきらめた時点の最深到達階を競う。

- 正式仕様: `docs/game-spec.md`（依頼書v1.1）
- 実装計画: `docs/IMPLEMENTATION_PLAN.md`
- 決定事項ログ: `docs/decisions.md`
- 受け入れチェック: `docs/checklist.md`

## 技術

- 単一HTMLファイル（`index.html` が公開正本）。Vanilla JS + Canvas 2D。外部ライブラリ・ビルド工程・画像/音声アセットなし
- 音声は一切なし（仕様）
- ランキングのみ Supabase（RESTを直接fetch。失敗してもゲーム進行は妨げない）
- 開発用検証: `tools/core-harness.mjs`（公開物ではない）
