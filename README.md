# 熊のFP探し（kuma_no_fpsagashi）

相棒のFP（ファーストパートナー）を探す熊になって、ダンジョンを一歩ずつ進むターン制ローグライクです。敵と戦い、拾った装備や食料を使いながら、地下60階の最終ボス撃破を目指します。

## どんな遊び？

- 一歩進む、攻撃する、足踏みすると敵も行動します。反射神経よりも、進む方向や道具を使うタイミングが大切です。
- ダンジョンを探索して下り階段を探します。階段では確認してから次の階へ進みます。
- HPだけでなく満腹度も管理します。食料を使わず満腹度が0になると、ターン経過でHPが減ります。
- 拾った武器・防具や道具を使って深い階へ挑みます。HPが尽きるかリタイアすると冒険終了。記録は最深到達階です。
- 現在のゲーム本体には地下60階のボス戦とクリア演出があります。「底なし」という旧説明とは異なり、終点があります。

## 操作

スマートフォンでは8方向パッドで移動し、「こうげき」「足踏み」「メニュー」を使います。PCでは矢印キー／テンキーで移動、Zで攻撃、Xで足踏み、Mでメニューを開きます。

## 遊び始めるには

ゲーム本体は [index.html](index.html) です。リポジトリをダウンロードまたはcloneし、手元の `index.html` をブラウザで開いてホーム画面から開始してください（GitHub上のリンクはソース表示です）。公開URLは下記のとおり未確認です。ランキング通信の成功やスマートフォン実機での動作を、このREADME更新で検証済みとはしていません。

## 技術

- 単一HTMLファイル（`index.html` が公開正本）。Vanilla JS + Canvas 2D。外部ライブラリ・ビルド工程・画像/音声アセットなし
- 音声は一切なし（仕様）
- ランキングのみ Supabase（RESTを直接fetch。失敗してもゲーム進行は妨げない）
- 開発用検証: `tools/core-harness.mjs`（公開物ではない）
